# Отчёт: ML-ранжирование автодополнения для C#

Дата: 2026-10-05. Движок общий с Go (https://github.com/dvislobokov/idea-ml-completion), методика та же, что в
`docs/REPORT-GO-RU.md`: разбиение по репозиториям, дедупликация, кэш файла λ=0.3, кросс-фиттинг LM и ранкера.
Подробности — `CHANGELOG.md` (e12).

## 1. Состояние

Для C# готовы языковая модель и ранкер на прокси-списках (синтетические списки кандидатов из идентификаторов файла и
топа LM). Адаптер C#-плагина (признаки из `NativeCSharpCompletion.items`, экспорт датасета, IDE-ранкер) ещё не начат;
контракт тот же, что реализован для Go (`docs/ADAPTER.md`), так что это перенос, а не новая разработка.

## 2. Корпус

| | локально | сервер |
|---|---|---|
| репозиториев C# | 15 | 737 (804 тыс. файлов, 6,2 ГБ) |
| доли: тест / LM / ранкер | 2 / 10 / 3 | 30 / 472 / 235 |
| файлов после дедупликации для LM | ~10 тыс. | 383 тыс. (310 млн токенов) |
| дубликатов удалено | — | 7 % |

Отложенные репозитории на сервере заметно «чужее» двух локальных (Flow.Launcher, Newtonsoft.Json): доля
идентификаторов вне словаря 32,9 % против 26,5 %, поэтому абсолютные цифры локально и на сервере не сравнимы напрямую.

## 3. Языковая модель

| модель | n-грамм | размер | перплексия | OOV | top-1 / top-5 следующего идентификатора |
|---|---|---|---|---|---|
| локальная, 10 репо (e07) | — | 29 МБ | 6,9 | 26,5 % | 0.371 / 0.639 |
| сервер, 472 репо, без отсечения | 27,4 млн | 162 МБ | 5,9 | 32,9 % | 0.380 / 0.620 |
| count 1,1,2,2 + repos 1,1,1,3 | 5,9 млн | 35 МБ | 6,2 | 32,9 % | 0.387 / 0.618 |
| **count 1,1,3,3 + repos 1,1,2,5** | 3,5 млн | **20 МБ** | 6,4 | 32,9 % | 0.388 / 0.615 |

В отличие от Go, отсечение по репозиториям стоит C# 0,3–0,5 перплексии: в C# больше повторяющегося сгенерированного и
шаблонного кода, который n-граммы одного проекта как раз и описывают. Для плагина всё равно подходит вариант 20 МБ.

## 4. Ранкер на прокси-списках

| | локально (e07) | сервер, без отсечения | сервер, LM 20 МБ |
|---|---|---|---|
| списков обучение / тест | ~180 тыс. / 24 тыс. | 721 тыс. / 111 тыс. | 721 тыс. / 111 тыс. |
| **ранкер MRR / top-1 / top-5** | 0.723 / 0.606 / 0.871 | **0.718 / 0.599 / 0.868** | 0.712 / 0.593 / 0.862 |
| только LM | 0.530 | 0.501 | 0.496 |
| самый частый в файле | — | 0.366 | 0.366 |

Ранкер даёт +0.22 MRR к чистой языковой модели, как и в Go. Ожидаемый выигрыш от PSI-признаков такой же, как в Go
(там на реальных списках плагина MRR вырос с 0.534 у правил до 0.783).

## 5. Следующие шаги

1. Адаптер C#-плагина: блок признаков из `NativeCSharpCompletion.items` (вид символа, доступность, соответствие
   ожидаемому типу, объявлен ли в файле), headless-экспорт датасета, тест паритета.
2. Обучение ранкера на реальных списках и сравнение с текущим порядком плагина.
3. Встраивание в IDE по образцу Go: subtree `ml/`, `completionRanker`, страница Smart Completion под флагом сборки.
