## Gotchas learned today
- Two train.py starts at once race on `lm.pathtok.u16` (os.replace of .tmp): start the second one a minute later.
- `fetch-catalog.sh` can hang on a giant mirror repo (curl max-time 900 × retries); kill the curl, the run finishes with an error line.
- `du -sh` over the corpora takes minutes; use `df`.
- GitHub API catalogue enumeration needs an authenticated `gh` (not logged in on this server; done on the user's machine this time).
