# Published models

Small enough to live in the repository; the corpora they were trained on are not here.

| file | what | notes |
|---|---|---|
| `cs-nn-31m-e1.cml` | C# transformer cs31m-e1 (30.9 M params, d512 × 8, BPE 16k, SPM/FIM), CMLN v1, int8 | trained 2026-10-06 on the **secret-scrubbed** C# corpus (5.65 G tokens); test ppl 3.97; whole-line shown 18 % at 92 % precision (see CHANGELOG e16). Carries the vocabulary sha256 in its meta. |
| `cs-16384.bpe` | the matching C# BPE vocabulary (`CMLBPE 1`, 16 384 ids) | loaded by `core.bpe.BpeTokenizer` |
| `cs-nn-31m-e2-lr2e3.cml` | C# transformer cs31m-e2-lr2e3 (same architecture; lr 2e-3 / 0.5 M batch, scrubbed corpus 5.65 G tokens) | trained 2026-10-07 (CHANGELOG e18): test ppl 3.80, rest of line exact 50.2 % healed (e1: 47.9 %) — **the C# model to ship** |
| `cs-nn-50m-e3-lr2e3.cml` | C# transformer cs50m (d640 × 10, 49.8 M params, int8, same data and recipe as cs31m-e2-lr2e3; DDP 62 min) | trained 2026-10-07 (e18): test ppl 3.60, rest of line exact 51.6 % (31 M: 50.2 %), fresh repos 43.5 % (40.9 %); 1.7× the compute of the 31 M model for +1.4 / +2.6 p.p. — the optional "big" C# model |
| `cs-ngram-e15-a.cml` | C# n-gram LM, order 5, MKN, 24-bit fingerprints, 32 MB | rebuilt 2026-10-07 on the full C# corpus (2.92 G lexer tokens): ppl 5.3, top-1 0.487 |
| `cs-rank-proxy-e15-a.cml` | C# linear ranker trained on **synthetic** lists | debugging only — proxy rankers do not transfer to real plugin lists (e17); a real C# ranker needs exported lists (e18) |
| `go-nn-31m-e2.cml` | Go transformer go31m-e2 (30.9 M, d512 × 8, BPE 16k, SPM/PSM FIM), int8, secret-scrubbed corpus 6.85 G tokens, lr 2e-3 / 0.5 M, DDP 49 min | trained 2026-10-07 (CHANGELOG e18): test ppl 2.99, rest of line exact 63.6 % healed (≤ 8 tokens 74.8 %), prod ≥ 0.8: 36 % shown / 97 % right — **the Go model to ship** |
| `go-16384.bpe` | Go BPE vocabulary (retrained 2026-10-07 after the server reinstall; sha256 770a316b…) | the Go models trained from e18 on use it |
| `go-ngram-e14-b.cml` | Go n-gram LM, order 5, MKN, 32 MB | rebuilt 2026-10-07 (3.93 G lexer tokens): ppl 4.6, top-1 0.510 on the new test fold |
| `go-rank-proxy-e14-b.cml` | Go linear ranker on synthetic lists | debugging only; the real-list ranker e17 (MRR 0.808) was lost with the server disk and must be re-exported (`tools/psi/`) |
| `parity-cs/` | PyTorch reference outputs for `NnParityTest`: 32 prompts with logits + greedy continuations, 500 positions × {plain, spm} | generated by `tools/nn/eval/make_parity.py`; lets any machine check that the Kotlin inference reproduces PyTorch bit-for-bit (scalar / native f32) |

The old Go model `go-nn-31m-e1.cml` was **not** published: it was trained before the secret filter existed (see CHANGELOG e16) and
may have memorised credentials from test fixtures in public repositories. It lives on the training server only; the next Go run
on the scrubbed corpus replaces it.

How to run the checks on another machine (Apple Silicon, Windows, Linux): `docs/MAC-CHECK-RU.md`.
