# Published models

Small enough to live in the repository; the corpora they were trained on are not here.

| file | what | notes |
|---|---|---|
| `cs-nn-31m-e1.cml` | C# transformer cs31m-e1 (30.9 M params, d512 × 8, BPE 16k, SPM/FIM), CMLN v1, int8 | trained 2026-10-06 on the **secret-scrubbed** C# corpus (5.65 G tokens); test ppl 3.97; whole-line shown 18 % at 92 % precision (see CHANGELOG e16). Carries the vocabulary sha256 in its meta. |
| `cs-16384.bpe` | the matching C# BPE vocabulary (`CMLBPE 1`, 16 384 ids) | loaded by `core.bpe.BpeTokenizer` |
| `parity-cs/` | PyTorch reference outputs for `NnParityTest`: 32 prompts with logits + greedy continuations, 500 positions × {plain, spm} | generated by `tools/nn/eval/make_parity.py`; lets any machine check that the Kotlin inference reproduces PyTorch bit-for-bit (scalar / native f32) |

The Go model `go-nn-31m-e1.cml` is **not** published: it was trained before the secret filter existed (see CHANGELOG e16) and
may have memorised credentials from test fixtures in public repositories. It lives on the training server only; the next Go run
on the scrubbed corpus replaces it.

How to run the checks on another machine (Apple Silicon, Windows, Linux): `docs/MAC-CHECK-RU.md`.
